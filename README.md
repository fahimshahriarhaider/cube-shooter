# Cube Shooter

A 3D wave-survival shooter built with the Godot Engine and GDScript. 

## 📖 About The Project
Cube Shooter is a browser-based 3D first-person shooter where the player must survive endless waves of enemies. As time passes, the difficulty increases, spawning more enemies that move faster. The goal is to survive as long as possible and get the highest score.

This project is currently in active development as a learning journey into 3D game development.

## 🎮 Controls
*   **W, A, S, D** - Move around
*   **Mouse** - Look around
*   **Spacebar** - Jump
*   **Escape** - Free the mouse cursor

## 🚀 Current Features (Day 1)
*   Fully functional 3D arena with boundary walls.
*   First-person player controller with mouse look and WASD movement.
*   Physics collisions (no falling through the floor!).
*   Dynamic lighting and sky environment.
